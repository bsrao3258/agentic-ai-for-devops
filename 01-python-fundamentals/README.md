# 01 — Python Fundamentals

Welcome! This module is the starting point for learners who are new to Python. Read the full **[Core Python Curriculum](CORE_PYTHON_CURRICULUM.md)** before moving to LLMs and agents.

## Recommended order

1. [Core Python Curriculum](CORE_PYTHON_CURRICULUM.md) — plain-English explanations, multiple examples per concept, expected outputs, exercises, and interview checkpoints.
2. [Runnable examples](examples_with_output.py) — one script that demonstrates the concepts in your local terminal.
3. [Expected output](EXPECTED_OUTPUT.md) — compare the output section by section.
3. [Starter examples](examples.py) — small exercises for classification and recommendations.
4. [Line-by-line code walkthrough](CODE_WALKTHROUGH.md) — explain each line of the existing starter code.
5. Complete the exercises at the end of the curriculum; do not skip straight to agent frameworks.

## Run the examples

From the repository root:

**Windows PowerShell**
```powershell
python .\01-python-fundamentals\examples_with_output.py
```

**Linux**
```bash
python ./01-python-fundamentals/examples_with_output.py
```

The script prints numbered sections for variables, operators, strings, lists, tuples/sets, dictionaries, conditions, loops, functions, comprehensions, paths, exceptions, classes, JSON, and environment variables.

## How to learn each concept

- Read the explanation in plain English.
- Predict the output before running the code.
- Type the example and run it.
- Compare your result with the expected output in the curriculum.
- Change the input and observe what changes.
- Explain the concept aloud as if answering an interview question.

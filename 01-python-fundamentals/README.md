# 01 — Python Fundamentals

## What you will learn
- Functions and parameters
- Strings and case-insensitive matching
- `if`, `elif`, and `else`
- Reading logs and writing testable functions

## Example
Run `python agent.py` from this directory.

The first exercise uses simple rules to classify known log messages. This is a foundation for later AI-agent work, not an LLM-powered agent yet.

## Interview practice
1. What is a Python function parameter?
2. What does `str.lower()` do?
3. How do `if`, `elif`, and `else` differ?
4. Why should troubleshooting logic be tested?

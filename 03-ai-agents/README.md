# 03 — AI Agents

## What you will learn
- Agent goals, state, decisions, and tools
- Difference between a rule-based script and an LLM-powered agent
- Human-in-the-loop approval
- Safe boundaries for automation

## Example
Run `python devops_agent.py`. This is a basic rule-based decision-flow demonstration, not a full autonomous AI agent.

## Interview practice
1. What makes a system an AI agent?
2. How does tool calling work?
3. When should an agent ask for human approval?
4. How would you limit an agent's production permissions?
